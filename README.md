## Project Overview
The primary objective of this project is to develop and evaluate deep learning architectures for the automated classification of Chest X-ray images for detecting covid19.

## Models & Methodology
The project explores two main approaches to extract visual features and classify the medical images:
* **Custom CNN.
* **DenseNet121.
